# Reference images (optional, not included)

The 8 pattern recipes in patterns.md are self-contained text: layout, measurements, colors, type behavior and a fill-in generation prompt for each pattern. You do not need any reference images to use this skill.

The original pack's 8 reference thumbnails are NOT distributed: they are third-party thumbnails collected for private layout study. If you want visual references, add your OWN reference images (or your own approved patterns) to this folder, named after the pattern ids in ../SKILL.md (01-ranking-rainbow-columns, 02-vs-split-worlds-big-numbers, and so on), and study them alongside the recipes.

Never reuse another creator's text, faces, logos or branding in generated output.
