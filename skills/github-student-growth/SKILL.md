# Free GitHub Repos for Students

Downloading a repo costs nothing; running it might not. So every entry below carries an audit across five axes - license, cost, hardware, setup, maintenance - verified live against the GitHub API on 6 November 2026. Licenses, URLs and activity change: re-verify on the day you publish.

## Tier 1 - coding and CS fundamentals

| Repo | License | Audit notes |
|---|---|---|
| [freeCodeCamp](https://github.com/freeCodeCamp/freeCodeCamp) | BSD-3-Clause | Free certifications (web dev, Python, data analysis, ML) that run in the browser on any laptop; very actively maintained. |
| [The Odin Project](https://github.com/TheOdinProject/curriculum) | CC BY-NC-SA 4.0 (per the repo license file; GitHub flags it as non-standard) | Free full-stack path. Learning and linking are fine; the non-commercial term means republishing their curriculum text inside your own content needs a second look first. |
| [OSSU Computer Science](https://github.com/ossu/computer-science) | MIT | Free self-taught CS degree path built on MOOCs - free to audit, certificates cost money (say so). Roadmap repos update slowly by nature. |
| [30 Days of Python](https://github.com/Asabeneh/30-Days-Of-Python) | none detected | Reading and learning is normal use; copying or republishing the text would need the author's permission. |
| [free-programming-books](https://github.com/EbookFoundation/free-programming-books) | CC-BY-4.0 | Free legal books in many languages; attribute when reusing the list. Very active. |

## If you make content about these

- One repo or one tier per post: what it is, who it suits, the five-axis audit line, and one first step the viewer can take today.
- Claim only what the audit shows. A repo list is a path, not a promise - never attach job or "job-ready" outcomes to it.

## Scoring a repo before featuring it (out of 100)

- License checked on the repo, reuse limits stated (25)
- Cost, hardware and setup described honestly for a basic laptop (25)
- Produces a real skill or portfolio artifact, no job promises (20)
- Maintenance verified, or staleness flagged (15)
- Fresh for your audience, not over-covered (15)
